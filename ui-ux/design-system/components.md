# Design Tokens: Component Specifications

## 1. Action Buttons
- Height: 48px
- Active feedback: scale(0.98), subtle ring focus
- High-visibility shadow for main CTA: `shadow-emerald-600/30`

## 2. Information Cards
- Clean flat border with 1px `border-slate-200`
- Generous padding: 20px - 24px
- Clear visual hierarchy with emojis/icons on top-right

## 3. Alerts & Banners
- Top-level urgent weather banner: Amber border + light amber background
- High accessibility contrast ratio (>= 4.5:1)
