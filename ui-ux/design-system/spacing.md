# Design Tokens: Spacing & Layout

- **Base Unit:** 4px (Tailwind standard)
- **Container Max Width:**
  - Mobile PWA: `100%` (padding `16px`)
  - Desktop Admin / Web: `1280px` (`max-w-7xl`)
- **Border Radius:**
  - Badges / Chips: `9999px` (`rounded-full`)
  - Buttons / Inputs: `12px` (`rounded-xl`)
  - Cards / Modals: `16px` - `24px` (`rounded-2xl`)
