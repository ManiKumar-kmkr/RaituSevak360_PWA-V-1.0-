# Design Tokens: Typography

## Font Family
- Latin & English: Inter, system-ui, -apple-system, sans-serif
- Telugu (Regional): Noto Sans Telugu, Suranna, Ramabhadra

## Scale
- Display / Greeting: `32px` / `2rem` (Bold / Extrabold)
- Section Title: `24px` / `1.5rem` (Bold)
- Card Header: `18px` / `1.125rem` (Semi-bold)
- Body: `14px` / `0.875rem` (Regular / Medium, Line height 1.5)
- Meta & Badges: `12px` / `0.75rem` (Semi-bold)
