# AI / ML Architecture (Python + FastAPI)

- **Framework**: FastAPI (Async high-performance HTTP microservice).
- **Core Pipelines**:
  1. **Crop Advisor**: Rule-based + ML hybrid system for stage-based agronomy.
  2. **Disease Diagnosis**: Computer vision classification models for crop leaf diseases.
  3. **Soil Intelligence**: Soil nutrient optimization models outputting targeted NPK deficiency corrections.
  4. **RAG & Vector Retrieval**: Semantic search powered by agricultural knowledge base vectors.
